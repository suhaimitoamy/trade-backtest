Sweep Acceptance Lab

Backtest Sweep/Reclaim dan Acceptance Breakout. APK memproses arsip secara lokal dan streaming, sehingga ratusan file bulanan serta jutaan candle tidak perlu diekstrak satu per satu.

Data dan parameter Web

Mode APK: file dipilih langsung dari penyimpanan atau Google Drive, ZIP dibuka otomatis, dan candle diproses satu per satu tanpa batas 250.000. Batas praktisnya hanya ruang cache, baterai, dan waktu proses perangkat.

Mode browser: hanya CSV kecil melalui API; batas 4 MB dan 250.000 candle tetap berlaku karena request Vercel.

Definisi yang diuji

Sweep low → BUY: low menembus rolling low, lalu close kembali di atas level dengan lower wick minimum.
Sweep high → SELL: high menembus rolling high, lalu close kembali di bawah level dengan upper wick minimum.
Acceptance above → BUY: beberapa candle close bertahan di atas rolling high; candle terakhir memiliki body kuat dan close dekat high.
Acceptance below → SELL: kebalikan acceptance above.
Eksekusi: signal pada close, entry next open, satu posisi aktif, time exit, biaya dalam R, dan SL-first saat SL serta TP tersentuh pada candle yang sama.
